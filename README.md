# ตัวแปลแชตเกม — เกาหลี → ไทย

แปลแชตในเกมแบบเรียลไทม์ สร้างตามสถาปัตยกรรมแบบไม่ประนีประนอม

---

## สถาปัตยกรรม

ทุกขั้นตอนทำงานพร้อมกัน ไม่รอกันเป็นทอด ๆ

```
[ปุ่มลัด Ctrl+1] ──▶ จับภาพ 1 เฟรม ──▶ OCR ──▶ แปลด้วย Ollama (บนเครื่อง) ──▶ แสดงผล
```

ไม่มีลูปสแกนอัตโนมัติแล้ว — กดปุ่มลัดเมื่อไหร่ค่อยจับภาพและแปลครั้งนั้น ประหยัด CPU/GPU
เต็มที่ตอนไม่ได้ใช้ และไม่มีความหน่วงจากการรอ diff เฟรมเหมือนโหมดสแกนต่อเนื่องเดิม

**จับภาพ** — Windows Graphics Capture ทำงานฝั่ง GPU จับได้แม้เกมเป็น Fullscreen Exclusive
ครอปกรอบแชตบน GPU ก่อนดึงลง RAM ถ้าเครื่องไม่รองรับจะถอยไปใช้ GDI เอง

**OCR** — PaddleOCR (โมเดลเกาหลี `korean_PP-OCRv5`) รันบน CPU (Mkldnn) ไม่แย่ง VRAM กับ Ollama/เกม
โมเดลฝังมากับแพ็กเกจ NuGet โดยตรง ผู้ใช้ปลายทางไม่ต้องโหลดไฟล์โมเดลแยกเองเหมือน Tesseract เดิม
บรรทัดที่ความมั่นใจต่ำกว่าเกณฑ์จะถูกทิ้ง ที่เหลือแต่ยังต่ำจะถูกทำเครื่องหมายสีส้มไว้เตือน

**คัดบรรทัดซ้ำ** — ใช้ระยะแก้ไข ไม่ใช่เทียบตรงตัว จึงทนต่อการที่ OCR อ่านบรรทัดเดิมเพี้ยนไปนิดหน่อยได้
กันไม่ให้แปลซ้ำถ้าสแกนทับพื้นที่แชตเดิมที่ยังไม่เลื่อน

**แปล** — ยิงไปที่โมเดลภาษาที่รันผ่าน [Ollama](https://ollama.com) บนเครื่องนี้เอง (ค่าเริ่มต้น `qwen3.5:9b`)
ไม่ต้องต่อเน็ต ไม่มีโควตา ไม่มีเรื่องโดนบล็อก IP

**Cache** — เก็บลงดิสก์ ข้ามการยิงโมเดลซ้ำสำหรับประโยคที่แปลไปแล้ว

**หน้าต่างคำแปล** — ล็อกแล้วเมาส์ทะลุผ่านไปที่เกมได้ กด `Ctrl+Shift+L` เพื่อสลับล็อก

---

## ติดตั้ง

**1. ไฟล์โมเดล OCR** — ไม่ต้องทำอะไร โมเดล PaddleOCR ภาษาเกาหลีฝังมากับแพ็กเกจ NuGet แล้ว
ครั้งแรกที่รันจะแตกไฟล์โมเดลลงดิสก์เองอัตโนมัติ

**2. Ollama** — ติดตั้ง [Ollama](https://ollama.com) แล้วดึงโมเดลไว้ครั้งเดียว
```
ollama pull qwen3.5:9b
```
เปิดโปรแกรมปุ๊บ โปรแกรมจะสั่ง Ollama โหลดโมเดลขึ้น RAM/VRAM ให้เองทันที (กัน
ไม่ต้องรอโหลดตอนกด Ctrl+1 สแกนครั้งแรก) ถ้า Ollama ยังไม่ได้รันอยู่เบื้องหลังจะลองสั่งเปิด
`ollama serve` ให้เองเงียบ ๆ ก่อนด้วย — ถ้าไม่มี `ollama.exe` อยู่ใน PATH จะขึ้นข้อความเตือนที่แถบสถานะแทน

โปรแกรมยิงไปที่ `http://localhost:11434` โดยอัตโนมัติ ไม่ต้องตั้งค่าเพิ่มถ้ารันบนเครื่องเดียวกัน
ถ้ารัน Ollama เครื่องอื่นหรือใช้โมเดลอื่น แก้ `OllamaUrl` / `OllamaModel` ใน config.json

**3. รัน**
```
dotnet run -c Release
```

## วิธีใช้

1. กด **เลือกกรอบแชต** ลากคลุมเฉพาะช่องแชต — ลากให้ชิดพอดี ยิ่งเล็กยิ่งเร็วและแม่น
2. กด **เริ่มแปล** (แค่เตรียมพร้อม ยังไม่สแกนจนกว่าจะกดปุ่มลัด)
3. ลากหน้าต่างคำแปลไปวางตรงที่ต้องการ แล้วกด **ล็อก**
4. เวลาต้องการอ่านแชต กด **Ctrl+1** เพื่อสแกนแล้วแปล 1 ครั้ง

กรอบและตำแหน่งหน้าต่างจะถูกจำไว้ ครั้งต่อไปไม่ต้องตั้งใหม่

## ตัวเลขที่ต้องดู

แถบสถานะล่างรายงานเวลาแต่ละขั้นแบบสด ใช้ตัดสินใจว่าต้องปรับอะไร

| อาการ | สาเหตุ | วิธีแก้ |
|---|---|---|
| OCR เกิน 300 ms | กรอบใหญ่ไปหรือ `OcrUpscale` สูงไป | ลากกรอบให้เล็กลง หรือลด `OcrUpscale` |
| อ่านตกหล่นบ่อย | ฟอนต์เล็กเกินไป | ตั้ง `OcrUpscale` เป็น 2.0 |
| เจอตัวอักษรมั่ว | เกณฑ์ความมั่นใจต่ำไป | เพิ่ม `MinConfidence` เป็น 65–70 |
| เชื่อมต่อ Ollama ไม่ได้ | ยังไม่ได้รัน หรือ URL/โมเดลผิด | เช็คว่า `ollama serve` ทำงานอยู่ และ `OllamaModel` ตรงกับที่ `ollama pull` ไว้ |
| แปลช้า | โมเดลใหญ่เกินสเปกเครื่อง (ไม่มี GPU/VRAM พอ) | ลองโมเดลเล็กลง เช่น `qwen2.5:7b` หรือรุ่น quantized |

ปรับได้จาก `%AppData%\GameChatTranslator\config.json`

## ข้อจำกัดที่ต้องรู้

**ความแม่นของคำแปลขึ้นกับโมเดลที่เลือก** โมเดลเล็กแปลไทยเพี้ยนหรือแข็งกว่าโมเดลใหญ่
ลองสลับโมเดลใน `ollama pull` แล้วแก้ `OllamaModel` ถ้าคำแปลไม่เข้าท่า

**ความผิดพลาดทบกันสองชั้น** ถ้า OCR อ่านผิดตั้งแต่ต้น คำแปลจะเพี้ยนหนักกว่าอ่านผิดเฉย ๆ
โปรแกรมจึงแสดงต้นฉบับเกาหลีควบคู่ไว้ให้เห็นเองว่าเพี้ยนตรงไหน ปิดได้จาก `ShowKorean`

**ยังไม่ได้คอมไพล์ทดสอบ** ผมเขียนโค้ดนี้ในสภาพแวดล้อมที่ไม่มี Windows และไม่มีเกมให้ทดสอบ
ส่วนที่เสี่ยงที่สุดคือ D3D11 interop ของ Windows Graphics Capture ถ้าพังจะถอยไป GDI เองอัตโนมัติ

---

## ถ้าอยากได้ความแม่นสูงกว่านี้อีก

ลองปรับ `OcrUpscale` ให้สูงขึ้น (เช่น 2.0) ถ้าฟอนต์เกมเล็กกว่า 16px ก่อน
ถ้ายังไม่พอ ลองปรับ `MinConfidence` (สเกล 0-1) ให้เหมาะกับฟอนต์เกมนั้น ๆ

## โครงสร้าง

```
Core/
  AppConfig.cs                    ค่าตั้งทั้งหมด
  Capture/
    ICaptureSource.cs             interface + GDI
    WgcCaptureSource.cs           Windows Graphics Capture (D3D11 interop)
  Ocr/
    TesseractOcrEngine.cs         OCR + กรองความมั่นใจ
    LineTracker.cs                คัดบรรทัดซ้ำแบบทนความเพี้ยน
  Translate/
    SlangDictionary.cs            แทนแสลงเกาหลีก่อนแปล
    TranslationCache.cs           cache ลงดิสก์
    OllamaTranslator.cs           แปลผ่านโมเดลที่รันบนเครื่องเอง (Ollama)
  Pipeline/
    ChatEntry.cs                  หนึ่งบรรทัดแชตและสถานะการแปล
    TranslationPipeline.cs        สายพานแบบทำงานพร้อมกัน
UI/
  MainWindow                      แผงควบคุมและตั้งค่า
  OverlayWindow                   หน้าต่างคำแปล ล็อกให้เมาส์ทะลุได้
  RegionSelectorWindow            ลากเลือกกรอบ
```
